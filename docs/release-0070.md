# meowdlm 0.0070 — 전노드 증명서 재유도, 실제 기본값 대조, 판별력 있는 음성 팔

리뷰가 지적한 결함 6건을 모두 인정하고 고쳤습니다. 핵심은 **"모든 노드 재유도"가 코드에 없었다**는
점입니다. 루트만 재유도하고 자손은 기록된 값을 신뢰했습니다.

## 결함 1 (핵심) — 자손 재귀 누락

증명서에 **부모→자식 파라미터 사슬**을 추가하고 검사기를 재귀화했습니다.

- 노드 형식: `(node 범주 결과ifv 의미항 params 자식...)` — `params` 는 부모가 시드한 치환표.
- 검사: 루트 `params` 는 `nilsub` 이어야 하고, 자식마다 **부모 subst 로 시드한 값 = 자식의 기록
  params** 를 확인한 뒤 자식으로 재귀합니다. 자식의 `ifv`·의미항도 그 자리에서 재유도해 대조합니다.

| 변조(레이아웃 보존, 6슬롯 유지) | 변조된 트리 | 수용 |
|---|---|---|
| 태그 `BOGUS` | 150/150 | **0** |
| 루트 ifv 값 위조(`n . 999`) | 150/150 | **0** |
| ifv 전부 `none` | 150/150 | **0** |
| ifv 키 삭제 | 150/150 | **0** |
| 의미항 위조(`(clause FAKE)`) | 150/150 | **0** |
| 손자 잎 수 변조(`rain`→`cats`) | 150/150 | **0** |
| 비문 유도(`the cat`→`a cats`) | 150/150 | **0** |

0.0069 에서는 손자 변조가 34/34·12/12 로 통과했습니다.

## 결함 2 — 기록된 ifv 가 장식이었음

`fg-ifv-eq` 를 **양방향 키 집합 일치 + `none` 은 `none` 끼리만**으로 바꿨습니다. 값 위조·키
삭제·all-`none` 세 팔이 모두 거부됩니다(위 표).

## 결함 3 — 음성 팔이 공허했음

- 모든 변조 팔을 **6슬롯 레이아웃 보존형**으로 다시 썼습니다(형태 불일치로 기각되지 않게).
- 각 팔은 **변조가 실제로 일어난 트리만** 세도록 바꿨습니다(`mut` 카운터). 초기 구현은 `mut=0`
  인 공허한 팔이었고, 그래서 0/150 이 아무것도 증명하지 못했습니다.
- **대조기 ablation** 을 게이트로 고정했습니다: `*fg-ifv-check*` 를 끄면 ifv 위조가 **150/150 수용**
  되고, 켜면 **0**. 팔이 값 대조를 실제로 시험한다는 증거입니다.

## 결함 4·5 — bind 덮어쓰기, fail-open guard

- `fg-c1-bind` 를 **조회 후 통일**로 교체했습니다. 제약 순서를 바꾼 두 선언이 같은 판정을 냅니다
  (`u1-sing false, u2-sing false, u1-pl true, u2-pl true`).
- 미등록 guard 술어는 **false(fail-closed)** 입니다(`GUARD-UNREG false`).

## 결함 6 — COP 보어 의미 소실

`Comp` 규칙 3종에 의미 슬롯을 넣었습니다.

```text
an mine was an fish  =>  (clause (np an mine) (vp was (comp (np an fish))))
```

## 결함 7 — 중복 워커 제거

`fg-m*` / `fg-im*` 이중 구현을 **규칙 조회 함수 하나만 갈아끼우는 단일 워커**로 통합했습니다
(`fg-lk-decl`, `fg-lk-idx`). 인덱스 경로와 스캔 경로가 구조적으로 갈라질 수 없습니다.
`fgw.l` 에서 하네스 함수명도 제거했습니다.
