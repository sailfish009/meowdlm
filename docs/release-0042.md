# meowdlm 0.0042 — OOV 흡수 실험: 벽은 어휘가 아니라 **단서 색인**에 있었다

리뷰의 다음 검증 기준 ①(OOV 30%+에서 흡수율 0% 벽 깨기)을 Maru 경로에서 직접 시도했습니다.
결과는 음성이고, 원인이 정확히 특정됐습니다.

## 측정 (프로브 170건: OOV 포함 97 / 정상 73)

| 팔 | OOV 97건 정확도 | 정상 73건 정확도 |
|---|---|---|
| **A 정확 일치(현행)** | **44/97 = 0.454** | **61/73 = 0.836** |
| B55/B70/B85 단서 문자열 치환 | 44/97 = 0.454 (변경 0건) | 61/73 = 0.836 |
| C70 유니그램 + 문자 2-gram 매핑 | 35/97 = 0.361 | 50/73 = 0.685 |

- **B 팔이 전혀 바뀌지 않은 것이 핵심 진단입니다.** 증거 표의 키는 `"there sparrow"` 같은
  **정확한 n-gram 문자열**입니다. OOV 단어를 유사어로 치환하면 그 단서는 표에서 사라지므로
  (미등록 키) 판정이 그대로입니다. OOV 흡수는 어휘 매핑 문제가 아니라 **단서 재추출** 문제입니다.
- C 팔은 n-gram 단서를 버리고 유니그램만 쓰므로 정보가 줄어 정상 구간까지 0.836 → 0.685로
  떨어집니다. 매핑이 잃은 것을 보상하지 못합니다.

## 결론 (반증)

가설 "문자 n-gram 근접 매핑이 OOV 흡수 0% 벽을 깬다"는 **이 데이터에서 기각**됩니다. 벽의 위치는

```text
사전(어휘)  ✗  — 매핑을 넣어도 판정이 변하지 않음
단서 색인   ✓  — 증거 키가 정확 n-gram 문자열이라 치환 시 키가 소멸
```

따라서 다음 순서는 **induct.l(원문 → 토큰/어간/n-gram 단서 추출)의 Maru 이관**이 선행 조건입니다.
리뷰가 지적한 "단서 추출 미이관"이 실험으로 확인된 셈입니다.

## 구현물

```text
src/meow/oov.l            문자 n-gram(접두 '#'+단어, 2-gram) 자카드 Q16 최근접 매핑
data/oov_vocab.l          어휘 554 + 단어별 gram 집합(24버킷)
experiments/parity/oov_start.l   A(현행) / C70(유니그램+매핑) 판정 출력
```

비용: A+C 두 팔 170건 **4.0초**(문자 매핑은 OOV 토큰 138개에 대해서만 수행).

## 경계

- 코퍼스 규모는 여전히 어휘 554·고유 입력 201입니다. 리뷰 기준의 5,000+/OOV 30% 규모는
  미달이며, 규모 확장 실험은 별도 코퍼스가 필요합니다.
- C 팔의 유니그램 축소는 매핑 효과만 분리하려는 설계입니다. n-gram 단서를 유지한 채 매핑을
  적용하는 경로는 단서 재추출 이관 후에만 가능합니다.
- 2-turn·영역 밖 지표는 이번에 재지 않았습니다(0.0041 수치 유지).
