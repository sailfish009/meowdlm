## 수치 교정 (분모 혼동)

`docs/experiment-0040-surface.md`의 "+15.1pp" 비교는 분모가 달랐습니다. 같은 분모로 다시 씁니다.

| 모델 | 영역 내(150) | 영역 밖 기권(20) | 전체(170) |
|---|---|---|---|
| 원본 MeowLLM step 2000 | 70/150 = **0.467** | 0/20 | 70/170 = 0.412 |
| Maru 0.0041 (게이트 없음) | 105/150 = **0.700** | 0/20 (전부 오수용) | 105/170 = 0.618 |
| Maru 0.0041 (OOV 게이트) | 67~85/150 = 0.45~0.57 | 18/20 | — |

판정 축은 **+23.3pp**(같은 분모). 영역 밖 축은 **여전히 약점**입니다: 게이트를 넣으면 18/20을
기권하지만 내용어 OOV 비율이 Python `fire_proto`와 다르게 계산돼(어형 매핑 `morph` 미이관) 영역 내
정확도가 0.700 → 0.45~0.57로 떨어집니다. 그래서 **게이트는 기본 경로에서 분리**(`e-decide-gated`)해
두고, 교정은 0.0042로 넘깁니다.
