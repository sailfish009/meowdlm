# meowdlm 0.0050 — 도출 증명서 + 독립 검사기 (Rocq식 작은 커널) + 계약/반례 (Silicon식)

0.0049의 자질 검사를 **증명서(트리 IR) + 독립 검사기**로 승격했습니다. Lean 의존타입이 주는
"구성상 옳음" 보증을 Maru 에서는 **검사기가 증명서를 재검증**하는 방식으로 대체합니다.

## 구조

```text
src/meow/certify.l
  노드 IR      (cat num case children) / 잎 (word num case ())
  선형화       c-lin — 작업목록 반복(상호재귀 회피)
  계약(사전)   c-contract  S: 주어수=동사수 · NP: det수=명사수 · VP: 목적어는 대격
  사후조건     c-post      선언된 노드 자질 = 자식에서 유도된 자질
  검사기       c-check     작업목록 + 경로 추적 → (ok, (kind detail path))
  생성기       c-mk-*      자질 지향(일치하는 트리만 생성)
  변조         c-mut-num / c-mut-leafnum
```

## 측정 (Maru)

```text
생성 트리 9개 → 검사기 수용 9/9 (100%)
변조 18건(노드 수 변경 9 + 잎 수 변경 9) → 거부 18/18 (100%)
반례 경로가 지목한 종류
  노드 수 변경  → post-feature S (계약 위반 S)
  잎 수 변경    → contract S (자식 수 불일치)
```

즉 생성기가 만든 트리는 정의상 계약을 만족하고, 손상된 트리는 **어느 노드에서 어느 자질이
어긋났는지**까지 돌려줍니다.

## 판정

1. **검사기 기반 보증이 성립합니다**: 9/9 수용, 18/18 거부, 반례 종류 지목. 생성기와 검사기가
   독립 경로라는 점(생성기는 트리를 조립하고, 검사기는 자식 자질을 다시 계산)이 핵심입니다.
2. **Rocq 커널과의 차이는 그대로 남습니다.** 증명서와 검사기를 우리가 만들었고, 검사기의
   정당성은 회귀 테스트(수용 9/9, 변조 18/18)로만 유지됩니다. 커널 검사가 아닙니다.
3. **일반 CFG 대조는 이번에 약합니다.** 33공리 CFG 어휘에 cat/dog/fish 가 없어 전부 거부
   (C0..C8=0)했습니다. 자질 제약의 효과는 0.0049 측정(`me sleep` 수용/거부)으로 보는 것이 맞습니다.

## 경계

- 트리 깊이 ≤ 3, 어휘 17단어의 소형 고정 집합. 대규모 문법에서의 검사 비용은 미측정.
- 변조는 노드 수·잎 수 두 종류만 주입했습니다(구조 교체·범주 교체는 미포함).
- `c-lin` 은 작업목록 반복이라 문장 길이에 선형이지만, 작업목록 재구성이 O(n^2)입니다.
