# meowdlm 0.0060 — 문법 규칙을 연역학습의 판정기로: 대체 가능성 검사

이번 릴리스는 요청하신 축에만 집중합니다: **영어 문법 규칙을 연역학습에 사용**하는 것.

## 연역적 구성 성분 정의

"스팬이 범주 C 의 구성 성분이다" ⇔ **같은 범주 스팬으로 교체해도 도출이 보존된다.**
이 정의를 9개 교체 시험으로 검증했습니다(`experiments/parity/subst60.l`).

## 측정 (Maru)

| 팔 | 통과 | 실패 |
|---|---|---|
| 기준 어휘 | **5/9** | 4 |
| 어휘 수정 후(cat→N, cats→N, box→N) | **6/9** | 3 |
| + 규칙 추가(VP→AUX NP), mine→N | 6/9 | 3 |

실패 4건과 그 원인(연역 검사가 지목한 기호):

```text
"the cat is mine"            reject → cat 이 (A) 로만 등재
"the cat chases the cats"    reject → cats 가 (A) 로만 등재
"the cat chases me"          reject → 주어 NP 가 cat 범주 오류로 실패
"the box are mine"           accept → box 의 V 범주 + mine 의 V 범주
```

즉 **대체 가능성 검사가 어휘 결함 3건과 규칙 결함 1건을 기호 수준으로 지목**했습니다. 수정 후 4→3으로
실패가 줄었지만 전량 해소에는 도달하지 못했습니다(남은 원인: `chases`·`are` 등재 확인과 규칙 조합).

## 판정

1. **문법 규칙은 연역학습의 판정기로 실제로 작동합니다.** 규칙·어휘 후보의 채택 여부가 도출 검사로만
   결정되고(0.0054 가지치기, 0.0056 규칙 심사), 이번 릴리스는 그 위에 **대체 가능성 정의**를 추가해
   실패를 기호 단위로 지목합니다.
2. **지목된 결함이 학습 대상입니다**: cat/cats/box/mine 의 범주 오류, VP→AUX NP 규칙 부재. 이것이
   연역 학습이 소비해야 하는 반례의 구체적 형태입니다.
3. 남은 3건은 이번에 수정하지 못했습니다(원인 미확정). 게이트는 **개선폭**만 단언합니다.

## 경계

- 9개 교체 시험은 손으로 만든 소규모 픽스처입니다.
- 어휘 수정은 시험쌍에 국한해 손으로 적용했습니다(자동 최소 수정은 미구현).
- 0.0058의 전체 게이트는 이번에 재실행하지 않았습니다.
