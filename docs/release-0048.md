# meowdlm 0.0048 — 0.0047 판정 철회: S 재귀 붕괴 차단 후 rules 발명은 **미성립**으로 확정

리뷰가 지적한 3건을 코드로 확인하고 고쳤습니다. 그 결과 **0.0047의 "6→12/100" 은 S 재귀 붕괴의
산물**이었음이 확인됐고, 교정 후 발명은 **훈련 도출 이득 0** 입니다.

## 교정 1 — 게이트 누락

`verify.sh`가 `tests/syntax-defect4.l`을 `tail -1`로 출력만 하고 단언하지 않았습니다. 이제
`defect4 true` 를 **단언**합니다(실패 시 게이트 중단).

## 교정 2 — S/CL 재귀 붕괴 (0.0047 보고의 근원)

원인: `g-find-any`가 시드의 **단항 규칙**(`S→CL`, `CL→NP|VP`, `NP→NG`, `VP→V` 등)까지 축약에
사용해, 실패 문장의 `PRON`·`N`·`V`가 모두 `S`로 승격됐습니다. 그 위에서 `(X0 (S AUX))` + `(CL X0)`
병합이 `S → S AUX`, `S → S PREP` 같은 **우측 재귀**를 만들어 비문을 대량 수용했습니다.

수정: 축약은 **발명 규칙(X… )만** 사용(`g-reduceX` + `g-xrules`)하고, 후보 구간에서 `S`·`CL`을
금지(`g-span-bad?`)했습니다.

검증(수정 후): `("i" "is" "and" "on" "very")`, `("box" "is" "is" "is")`, `("i" "in" "of" "with")`
→ **전부 거부(nonsense 수용 0)**.

## 교정 3 — 음성 프로토콜 + banned 핑퐁

- 역순 단독 프록시 → **내용어 셔플**(기능어 위치 고정, 내용어 순서만 뒤집기)로 교체.
- `banned` 를 **누적 리스트**로 고쳐 기각 이력이 덮이지 않게 했습니다(0.0047의 핑퐁 버그).
- 학습 50문장 / **held-out 100문장(corpus[50:150])** 분리 측정.

## 판정

1. **0.0047 의 "6→12/100" 은 철회합니다.** S 재귀 붕괴가 만든 수용이었고, 붕괴를 막으면 훈련
   도출 이득이 **0**입니다.
2. held-out 은 5→8로 소폭 늘지만, 손 33공리(33/100)의 1/4 수준이고 규칙 수는 34로 동일합니다.
   **규칙 발명은 현재 미성립**입니다.
3. 셔플 수용이 시드와 동일(2)하고 비문 수용 0이라는 점은 "게이트가 작동한다"는 증거일 뿐,
   "문법을 배웠다"는 증거가 아닙니다.
4. 0.0045·0.0046·0.0047 의 발명 수치는 모두 이 붕괴 또는 'A' 편향이 섞인 값입니다. **세 릴리스의
   발명 수치를 철회**하고 이 표를 기준으로 삼습니다.
