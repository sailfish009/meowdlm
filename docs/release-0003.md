# meowdlm_v0.0003 — 단서 추상화 실험: 변수 패턴(anti-unification 계열) + 하위어 단서

그리고 그 원인을 측정했습니다.

## 원인 진단 (이 실험의 실제 산출물)

| 항목 | 값 |
|---|---|
| 생성된 단서 수 | base 6,294 / gap 14,003 / char 7,047 / gap+char 14,756 |
| 채택된 단위 | 197 / 196 / 195 / 194 (변화 없음) |
| 채택 단위의 가족 구성 (char arm) | lex 117, char 64, gap 7, skel 7 |
| 프로브 OOV 토큰 | 136회 / 고유 126개 |
| **OOV 흡수율** | **0.0%** (136회 중 0회가 채택 단서에 걸림) |
| OOV 단어의 철자 5gram 최근접(자카드) | `little`, `sofa`, `carton`, `puppy`, `bark`, `hoover` … 전부 0.00 |

두 가지가 동시에 막습니다.

1. **채택 검사**가 추상화 단서를 걸러냅니다. 생성 14,756개 중 194개만 남습니다 — 순도(≥0.5)와
   음성 커버리지(≤1)를 동시에 만족하는 비연속·부분 단서가 15범주·고유입력 201개 코퍼스에서는
   거의 없습니다.
2. **증거 기반 자체가 부족합니다.** 프로브 OOV 126개 단어가 코퍼스 어휘 225개와 철자 5gram을
   전혀 공유하지 않습니다. `puppy`↔`pup`, `sofa`↔`couch` 같은 연결은 철자가 아니라 의미의
   연결이고, 철자 단서로는 닿지 않습니다.

## 판정

1. **추상화 기계를 넣어도 정확도는 오르지 않습니다**(최대 +0.7pp, 1문항, p=1.0). 이 라인에서
   추론 구조는 병목이 아닙니다.
2. **병목은 증거 기반(어휘·바꿔쓰기 커버리지)입니다.** 같은 코퍼스에 어휘 다리만 주면 0.487 →
   0.713(0.0292 사전 포함 조건)까지 오릅니다. 그 다리는 학습으로 유도된 것이 아니라 사람이
   프로브를 보고 만든 것이었습니다(0.0002에서 확인).
3. 따라서 다음 실험은 모델 구조가 아니라 **데이터**입니다: 같은 개념을 다른 표기로 반복하는
   문서를 수집해야 합니다(0.0284가 웹 코퍼스에서 쓴 방법과 같은 원리).
