선언 하나가 유일한 문법 원천입니다.

```lisp
(define *fg-decl*
  (list (list 'S (list 'Sbj) (list 'VPred))
        (list 'Sbj (list 'DET (list 'n '$sn1)) (list 'N (list 'n '$sn1) (list 'bind '$sp1 3)))
        (list 'Sbj (list 'PRON (list 'n '$sn1) (list 'p '$sp1) (list 'c 0)))

                           (list 'guard 'intr '$v1 '$v1)
                           (list 'guard 'agree '$vp1 '$vn1 '$sp1 '$sn1)))
        ...))
(def-fg *fg-pilot*)   ; → (lambda (toks) ...) 와 (lambda (n) ...) 쌍을 만든다
```

제약 종류는 셋입니다: `(특질 변수|리터럴)` 통일, `(bind 변수 리터럴)` 비단말 인터페이스
자질 고정(명사구의 인칭 3), `(guard 술어 변수...)` 명명 술어(`intr`, `tr`, `agree`).

## 구현 중 드러난 Maru 사실 (관측됨)

1. **`?x` 는 심볼이 아니라 문자 리터럴**이다(`?p` → 112). 자질 변수는 `$p` 로 써야 한다.
   0.0040 이래 선언형 문법을 안 쓴 이유 중 하나로 보인다.
2. **빈 리스트를 car 로 쓰는 cons 는 만들 수 없다.** `(cons () x)` 는 x 가 되어 대안 목록이
   깨진다. 치환(subst)은 빈 리스트 대신 표식 항목(`(zz . 0)`)으로 시작해야 한다.
3. **상호 재귀 순방향 선언은 `sx.py sort` 와 충돌한다.** 정렬기가 `(define f ())` 를 정의로
   보고 사용 지점 뒤로 옮겨 실제 정의를 덮어썼다(이번에 `fg-gjoin`/`fg-gwords` 가 `()` 로
   덮여 실패). 순방향 선언은 **별도 파일**(`fgw.l`)로 분리해야 한다.
4. **`string-append` 가 없다.** 문자열 결합은 문자코드 목록 병합 + `list->string` 으로 한다.
5. **`define-function` 은 첫 본문 형식만 취한다.** 여러 줄로 나눠 쓰면 두 번째 이후 형식이
   조용히 사라져 함수가 `()` 를 돌려준다(진단에 오래 걸린 지점). 제약 분기는 헬퍼 함수로
   쪼개야 한다.

## 경계 (관찰된 한계)

- **비단말 인터페이스 자질은 자동 전파되지 않는다.** 부모 쪽 제약은 터미널에서만 검사되므로,
  명사구의 인칭 3 같은 값은 `bind` 로 명시해야 한다. 자동 전파에는 전개 후 제약 검사 단계가
  필요하다.
- **`agree` 가드는 인칭 미바인딩을 `-1`(무관)로 정규화**해 처리한다. 정규화를 빼면 관대한
  쪽으로 틀린다(초기 구현이 `i sleep` 을 거부).
- 생성 가지치기는 단계당 6개로 제한한다(`fg-limit`). 제한이 없으면 대안 목록이 폭발해
  깊이 가드에 걸린다.
- **`a`/`an` 선택 규칙은 두 검사기 모두에 없다**(`an cat` 이 수용됨). 음운 조건은 미구현이며,
  선언에 술어를 추가하면 같은 방식으로 확장된다.
- 15범주 전체 표면 실현 연결은 아직입니다. 이번 파일럿은 자질문법(S/NP/VP/Obj/Comp) 범위입니다.
