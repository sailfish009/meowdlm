## 정직한 경계

1. **C 구성은 범위 밖 탐지를 포기합니다**(0.600 → 0.000). "항상 답한다"는 요구를 맞추기 위한 교환이고,
   B 구성은 그 축을 유지합니다. 유틸리티(정답 또는 되묻기)는 B가 더 높습니다(0.618 vs 0.565).
2. **새 문자열의 품질은 검증되지 않았습니다.** compose는 개체 치환이므로 문법은 틀 안에서 유지되지만,
   의미 적합성을 독립 평가하지 않았습니다.
3. **원본 비교는 공개 체크포인트 1개**(step 2000) 조건입니다.
4. **RSS는 두 모델이 같은 프로세스에서 측정**되어 분리되지 않았습니다.
