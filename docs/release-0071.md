# meowdlm 0.0071 — 458어휘 문법의 의미항·증명서, 대명사 해소, 수 동치 조회

sem-loop-1 세 실험을 이 트리로 이관했습니다. 0.0070 은 **fixture 48어휘 6슬롯 문법**에서만
트리·의미항·증명서를 낼 수 있었습니다. 1,000문장 코퍼스의 286 도출문은 인식기(`syn-accepts`)만
통과하고 트리·의미항이 없어 후속 학습의 입력이 될 수 없었습니다. 이번 릴리스는 그 입력을 만듭니다.

## 1. 의미항 파서 (`src/meow/sem.l`)

33규칙 문법 위 span 팩킹 파서(세포당 3개). 규칙별 의미항 조립표 + 노드 증명서 재유도 검사.

| 항목 | 값 |
|---|---|
| 인식기 수용 | 286/1000 |
| 파서 도출 | **286/1000 (문장 단위 불일치 0)** |
| 의미항 생성 | **286/286** |
| 증명서 재유도 | **286/286** |
| 독립 오라클(`tools/sem_oracle.py`) | 286 / 286 / 286 |

의미항 형식은 `(clause <np…> <vp…>)` 입니다. 예: `(clause (np the couch) (vp warmer none))`.

## 2. 대명사 해소 (`src/meow/an.l`)

- **R1** 목적어 대명사 + 같은 절 주어가 비대명사·수 일치 → 주어로 해소
- **R2** 최근 3절 명사를 최근 순으로 훑어 수 일치 첫 명사로 해소
- **R3** 1·2인칭 → `deictic` 기권, 후보 0 → `no-candidate` 기권

| 항목 | 값 |
|---|---|
| 고정 20케이스(라벨 손작성) | **20/20** (해소 15, 기권 5) |
| `nm.l` 원자 대명사 인자 | 96 → **상수 잔존 0** (해소 12, 기권 84) |
| 코퍼스 286 의미항의 대명사 | 75건, 전부 1·2인칭 → 해소 0 |
| 독립 오라클(`tools/an_oracle.py`) | 75/75 일치 |

코퍼스 대명사가 전부 1·2인칭이라는 사실은 이 코퍼스가 대화체임을 뜻하며, 담화 지시 해소를
시험할 수 없다는 정직한 한계입니다.

## 3. 수 동치 조회 (`src/meow/nm.l`, `src/meow/eq.l`, `tools/eq_build.py`)

의미항 → 원자 명명층(`nm.l`)과 수 동치 계층(`eq.l`)을 넣고, KB 조회 3팔을 게이트로 고정했습니다.

| 팔 | 정의 | 정답률 | 오답 |
|---|---|---|---|
| off | 정확 일치(동치층 없음) | **0/40** | 0 |
| on | 복수→단수 동치 | **40/40** | 0 |
| 붕괴 | 모든 명사를 `thing` | **0/40** | **40** |

붕괴 팔은 조회 성공 40/40, 정답 0, 오답 40 입니다. 조회 성공률만 보면 과잉 병합을 놓칩니다.
`tools/eq_oracle.py` 와 124줄 완전 일치합니다.

## 4. 재현성 수정 (0.0070 에서 물려받은 결함 3건)

전체 `verify.sh` 를 fresh 셸에서 돌려 드러난 결함입니다. 0.0070 트리에서도 동일하게 재현됩니다.

| 결함 | 증상 | 수정 |
|---|---|---|
| 참조 구현 경로 하드코딩 | `diff_horn.py` 등 5곳이 `/research/meowdlm_v0.0039` 를 가리켜 `ModuleNotFoundError: kernel` | `MREF` 환경변수(기본 `/research/BACKUP/meowdlm_v0.0039`) |
| `$MARU` 미export | §37 이 서브프로세스에서 `maru` 를 찾다가 빈 출력 → IndexError | `export MARU` |

세 수정 전에는 전체 게이트가 §2/§31 에서 멈췄습니다. 수정 후 §1–§40 이 순차 통과합니다.

## 한계

- 의미항은 구성소 구조 기반입니다. 격·수·한정 의미는 담지 않으며, 판정기의 사각지대
  (`a animal` 같은 a/an 교체, 수 미지정 어휘 `mine`)는 그대로 남습니다.
- VP 의미는 머리 동사 + 첫 NP 만 남깁니다(TRAIL 은 버립니다).
- 수 동치 대상은 단·복수뿐입니다. 동의어·환유·어구 변이는 범위 밖입니다.
- KB 98원자는 fixture 48어휘 유래입니다. 458어휘 코퍼스 원자에 명명층을 적용하는 것은 다음 과제입니다.
- Maru 는 꼬리 호출 최적화가 없어 1,000문장을 한 프로세스에서 돌리면 재귀 가드에 걸립니다.
  구간 실행(`*sm-start*`/`*sm-limit*`)으로 쪼개 5청크로 돌립니다.
