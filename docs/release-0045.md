# meowdlm 0.0045 — 구 구조 규칙을 스스로 발명할 수 있는가 (최소 시드 + 쌍 병합 + 허가 게이트)

리뷰 1번 과제: 고정 33공리를 최소 시드로 낮추고, 실패 문장에서 규칙을 **발명**한다.

## 구조

```text
시드 14규칙   S→CL, CL→NP VP|VP|NP, NP→DET NG|NG|PRON, NG→N|A NG|N PP,
              VP→V|V NP|V PP, PP→PREP NP            (고정 33공리의 최소 골격)
발명 연산     실패 문장의 범주열을 현재 병합 규칙으로 축약 → 인접 쌍 빈도 집계
              최빈 쌍 (A B) 에 대해  X→A B, CL→X  추가 (BPE/Sequitur식)
              + 접기(fold): 기존 규칙 우변에 (A B) 가 나타나면 X 로 치환한 변형 추가
허가 게이트   빈도 ≥ 2 (일반화), 역순(음성) 수용률이 시드보다 나빠지지 않을 것
```

## 측정 (코퍼스 100문장, 병합 16회)

| 문법 | 규칙 수 | 도출 | 역순 수용(음성) |
|---|---|---|---|
| A 시드 | 14 | **6/100 = 0.060** | 3/100 = 0.030 |
| B 발명(시드 + 16병합) | 46 | **9/100 = 0.090 (+3.0pp)** | 3/100 = 0.030 (불변) |
| F 손으로 쓴 33공리 | 33 | **41/100 = 0.410** | 16/100 = 0.160 |

200문장·24병합에서도 같은 방향: 시드 9 → 발명 19, 손 68 (규칙 62 vs 33).

## 판정

1. **발명은 작동한다.** 시드 0.060 → 0.090. 게이트를 통과한 병합만 채택했고, 역순 수용률은
   0.030 로 **전혀 오르지 않았습니다**(과일반화 없음).
2. **효율은 크게 뒤진다.** 같은 코퍼스에서 손으로 쓴 33공리는 0.410 인데, 발명은 규칙 46개를
   써서 0.090 입니다. 규칙 1개당 도출 이득이 손 문법의 약 1/9 입니다.
3. **원인은 병합의 의미론이다.** 쌍 병합은 `X→A B` + `CL→X` 를 만들 뿐이라, X 가 **절 위치에서만**
   쓰입니다. 접기(fold)를 넣어도 X 가 기존 규칙 내부에 들어가지 않아 문장 중간 구간을 덮지
   못했습니다(실측: fold 유무 결과 동일). 즉 압축은 되지만 **구성 성분(phrase)을 만들지 못합니다.**
4. 따라서 "규칙을 스스로 배운다"는 이 방식으로는 **시드 위의 미세 보정**에 그칩니다. 손 문법을
   대체하려면 병합이 만든 기호를 통사 위치 전반에 쓸 수 있어야 하고(비단말 대체 + 자질),
   그것이 다음 과제입니다.

## 경계

- 코퍼스 100문장 표본, 병합 16회. 200/24 결과 병기.
- 음성은 역순 프록시입니다(0.0038 의 내용어 셔플과 다름).
- 33공리도 사람이 쓴 것이라 "정답 문법"이 아닙니다. 비교는 규칙 수 대비 도출 효율로만 읽어야 합니다.
