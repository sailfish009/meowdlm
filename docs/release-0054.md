# meowdlm 0.0054 — 검증된 학습의 Maru 이식: 도출 보존 어휘 가지치기

방향 전환 제안을 그대로 채택했습니다. 새 학습을 발명하는 대신, **이미 검증된 학습(Python 0.0035
최소 모호성 확정)** 을 Maru 로 옮겼습니다.

## 구현

```text
src/meow/lexfix.l
  lx-try       단어 w 의 범주 c 를 제거한 어휘로, w 가 나오는 **모든 문장** 재도출 검사
  lx-pass      모호 단어마다 후보 제거 시도(채택/철회), 사유별 카운트
  lx-prune     라운드 반복(최대 6), 단어당 최소 1범주(floor=1) 유지
게이트는 기존 것을 그대로 재사용: 도출 보존 + 셔플(역순) 비증가 + held-out 비감소
```

## 측정 (코퍼스 train 200 / held-out 200, Maru)

| 상태 | 어휘 범주 총수 | 모호 단어 | train 도출 | held-out 도출 | 역순 수용 |
|---|---|---|---|---|---|
| 이전 | 599 | 89 | 68/200 | 56/200 | 27 |
| **이후** | **580 (−19)** | **75 (−14)** | **68/200 (보존)** | **56/200 (보존)** | **27 (비증가)** |

## 판정

1. **도출 보존이 정확히 성립합니다**(train 68→68, held-out 56→56). 0.0035 의 보존 법칙이 Maru 에서
   재현됩니다.
2. 모호성은 599→580, 모호 단어 89→75 로 줄었습니다. **Python 0.0035 의 26→2 에는 미달**합니다.
   이유는 명확합니다: Python 판은 **도출 지지(support) 역추적**으로 "어떤 성공 도출에도 쓰이지 않은
   후보"를 먼저 제거했고, Maru 판은 그 정보가 없어(현 syntax.l 은 true/false 만 반환) 재도출 검사만
   으로 줄입니다. 즉 **도출 증인(트리) 반환이 다음 선행 조건**입니다.
3. 셔플 수용은 27→27 로 늘지 않았습니다. 이 축의 이득은 판별력이 아니라 **어휘 해석의 명료성**이며,
   0.0035 측정(거부율 +0.003)과 같은 크기입니다.
