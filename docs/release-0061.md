# meowdlm 0.0061 — 반례 표적 최소 수정 루프: 단일 편집으로는 불가 (측정된 음성)

## 설계

연역 루프: 실패한 시험쌍 하나를 **고치는 최소 편집**을 찾고, 이미 통과한 쌍을 깨지 않으며, 코퍼스
도출이 줄지 않을 때만 채택. 후보 132개 = (14단어 × 9범주집합) + 6규칙 추가.
판정 오라클 = `syn-accepts`(문법), 목표 라벨 = `lf-check`(자질 검사).

## 측정 (Maru)

```text
START  agree=3/9  cov=27/60  cands=132
FINAL  agree=3/9  cov=27/60  adopted=0
```

**132개 단일 편집 중 채택 0건.**

## 판정 — 왜 단일 편집으로 안 되는가 (수정 불가 지점의 구조)

| 실패 쌍 | 필요한 수정 | 단일 편집으로 불가능한 이유 |
|---|---|---|
| `the cat is mine` | `cat→N` **그리고** `VP→AUX NP` | 두 편집이 동시에 필요 |
| `me sleep` | `me`의 격 제거 | `me`를 PRON에서 빼면 `the cat chases me`(목적격)가 깨짐 |
| `the box are mine` | `box`의 V 제거 **그리고** `mine`의 V 제거 | 둘 중 하나만 고치면 다른 경로로 여전히 도출 |

핵심은 마지막 두 줄입니다. **격(case)과 수 일치가 문법(도출)이 아니라 어휘 평면에만 있어서**,
어휘를 고치면 다른 문장이 함께 깨집니다. 0.0049에서 자질 검사기(`lf-check`)가 격·수를 정확히
판정했지만, 그 자질이 Earley 도출에 전달되지 않습니다.

## 결론

**수정 대상은 어휘 항목이 아니라 문법 자체입니다**: 자질을 담은 비단말(예: `NP[case]`)과 도출 중
통일(unification)이 필요합니다. 그 위에서야 "어휘 한 항목 수정"이 국소적으로 성립합니다.

## 경계

- 시험쌍 9건·후보 132개는 손으로 정한 소규모 집합입니다.
- 목표 라벨을 `lf-check`로 둔 것은 자기 일관성 검사이며, 외부 정답 라벨이 아닙니다.
- 0.0058 전체 게이트는 이번에 재실행하지 않았습니다.
