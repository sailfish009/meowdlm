# meowdlm 0.0062 — 자질을 도출 판정에 결합 + 학습 경험 자동 기록

0.0061의 결론(자질이 도출에 없어 어휘 국소 수정이 불가능)을 두 단계로 해소했습니다.

## 1. 자질 결합 수용 판정 (`src/meow/featgate.l`)

```text
fg-accept(toks, lex, rules, mode)
  = syn-accepts(구조 도출)  AND  (자질 미상이면 구조 판정, 알면 lf-check)
```

## 2. 측정 (Maru)

| 팔 | 9케이스 일치 | 코퍼스 60 도출 |
|---|---|---|
| struct (0.0061 기준) | **3/9** | 27/60 |
| +자질 게이트 | **6/9** | 27/60 |
| +반례 기반 어휘 수정 | **9/9** | 27/60 |
| **+경험 저장 후 적용** | **9/9** | — |

수정 4건(반례가 지목한 기호): `cat→N`, `cats→N`, `chases→V`, `chase→V`.
자질 게이트만으로 +3, 어휘 수정으로 +3 더, 합계 **3/9 → 9/9**. 코퍼스 도출은 27/60으로 **보존**됩니다.

## 3. 학습 경험 자동 기록 (`src/meow/learn.l`, `src/meow/exp.l`, `src/meow/apply.l`)

```text
RECORDED L=4            학습 호출이 L 레코드 4건 생성
SAVE 1361546548         해시 검증 저장
RELOAD (1361546548 4)   재로드 일치
applied=9/9             저장된 경험만으로 상태 복원 후 재측정 → 동일 판정
```

`apply.l`에 L "added" 처리를 추가해 **추가·제거 양방향** 경험을 적용할 수 있게 했습니다.

## 판정

1. **자질이 판정에 들어와 격·수 위반이 문법 수준에서 차단됩니다** (`me sleep` 거부, `chases me` 수용을 동시에).
2. **경험이 학습에서 자동 생성되고 재시작 후 복원**됩니다(4→reload→9/9).
3. 코퍼스 도출은 손실 없이 유지됩니다(27/60).

## 경계

- 자질 게이트는 자질 어휘(45단어)에 있는 문장에만 적용되고, 미지어는 구조 판정으로 폴백합니다.
- 9케이스의 목표 라벨은 `lf-check`(자기 일관성 검사)이며 외부 정답이 아닙니다.
- 어휘 수정 4건은 반례가 지목한 것을 손으로 채택했습니다(자동 탐색은 0.0061에서 0건).
- 전체 verify.sh는 이번 릴리스에서 재실행하지 않았고, §27·§28·§29만 확인했습니다.
