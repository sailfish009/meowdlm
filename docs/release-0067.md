# meowdlm 0.0067 — 지역 치환표 + 특질 이름 기반 인터페이스, 유도 트리/증명서 복구

리뷰가 지적한 결함 2건을 인정하고 고쳤습니다. 둘 다 실제 결함이었습니다.

## 결함 1 (수정) — 비단말 호출 인자 미사용, 전역 치환표 의존

이전 구현은 비단말 분기에서 `(cdr kid)`(호출부 제약)를 버리고 단일 전역 치환표 `s` 의 동명 변수
공유로만 자질을 전달했습니다. 결과가 두 가지로 드러났습니다.

| 반례 | 이전 | 지금 |
|---|---|---|
| 알파 치환 `(Sbj (n $x) (p $y))` 안에서 자식이 다른 이름 사용 | `the cats sleeps` **수용** | **거부** |
| 동일 비단말 재사용 `(S (Obj) (CONJ) (Obj))` | `the cat and the dogs` **거부** | **수용** |

수정 방식은 리뷰 지시대로입니다.

- 규칙마다 **자기 치환표**에서 평가합니다(`fg-mrule` 이 `fg-nilsub` 로 시작).
- 호출부 제약은 **특질 이름 기준**으로 자식 치환표에 주입됩니다(`fg-seed`).
- 자식이 완료되면 `=>` 인터페이스 값(`fg-ifvals`)을 호출부 변수와 통일합니다(`fg-cmatch`).
- 이제 `fg-if1` 의 특질 이름 `f` 도 실제로 쓰입니다(시드·매칭 키).

## 결함 2 (수정) — 이빨 팔의 교란 변수

이전 TEETH 선언은 타동사 규칙과 `Obj → DET N` 을 뺀 축소 선언이라, 0/9 가운데 7건은 **규칙 누락**에
의한 거부였습니다. 리뷰 지적이 맞습니다. 이제 이빨은 **전체 11규칙 원본의 단일 차분**입니다.

측정 결과 두 가지가 새로 드러났습니다.

| 팔 | 결과 | 해석 |
|---|---|---|
| 기준 선언(정상) | 9/9 수용 | 비교 기준 |
| `S` 기본값만 1로 변경 | **9/9 수용** | 기대와 다름 — 아래 참조 |
| `Sbj` 기본값만 3→1 | 3/9, **NP 3인칭 단수 표본 0/6** 수용 | 이빨이 실제로 문다 |
| `i sleep` (1인칭 양성) | 두 차분 모두 **true** | 과잉 차단 없음 |

`S` 차분이 무해한 이유는 의미론이 바뀌었기 때문입니다. `S` 의 인터페이스는 **호출자에게 돌려주는
결과**이고 `S` 에는 호출자가 없으므로 내부 판정에 닿지 않습니다. 0.0066 의 전역 치환표에서는 같은
변수가 내부 가드와 공유되어 0/9 가 나왔습니다. 즉 그 0/9 는 "값 대조의 힘"이 아니라 "변수 공유의
부작용"이었고, 리뷰가 요구한 게이트를 그대로 쓰면 의미론 변화를 못 잡습니다. 그래서 **행동에 닿는
자리(`Sbj`)의 단일 차분**으로 이빨을 옮겼습니다.

남은 누수 1건은 `he eats an fish` 입니다. `Sbj` 의 `PRON` 분기는 기본값이 없고 어휘가 인칭 3을
바인딩하므로, `Sbj` 기본값 차분이 닿지 않는 가지입니다. 게이트는 NP 주어 표본으로 한정해
`np3sg-wrongly-accepted=0` 을 단언하고, PRON 가지는 문서에 남깁니다.

## 유도 트리·증명서 (복구)

0.0065 에서 철회했던 축을 리뷰 §3 규약대로 복구했습니다.

- 잎: `(leaf 범주 단어)`
- 노드: `(node 범주 ((특질 . 값)...) 자식트리...)`
- 생성기 항목을 `(치환표 단어목록 트리 자식목록)` **4-슬롯**으로 분리해, 잎/노드와 자식 목록이
  같은 자리에서 섞이지 않게 했습니다.

| 항목 | 값 |
|---|---|
| 생성 트리 | 150 |
| 구조·잎 검사(`fg-chk`) 통과 | **150/150** |
| 선형화 재파싱 통과 | **150/150** |

**검사기가 하지 않는 것**: 인터페이스에 매개변수/결과 구분이 없어 "부모 특질과 자식 특질의 이름
일치"를 요구하면 목적어 수까지 주어 수에 묶이는 오탐이 납니다(초기 구현에서 VPred 25/150 오탐).
그래서 `fg-chk` 는 구조·잎을 검사하고, 자질 일관성은 선형화 재파싱이 맡습니다. 자질 유도 관계를
증명서 안에서 재유도하는 일은 미착수입니다.
