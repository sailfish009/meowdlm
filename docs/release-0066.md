# meowdlm 0.0066 — 인터페이스 자질: "채우기"에서 "검사"로

0.0065 는 부모가 기본값을 **채우기만** 했습니다. 내부가 값을 이미 바인딩했으면 대조 없이 통과했고,
저는 그 점을 경계로 기록했습니다. 이번 릴리스는 그 구멍을 닫고, 검사가 실제로 작동하는지를
**고의로 틀린 선언**으로 반증합니다.

## 변경

`fg-if1`: 인터페이스 항목이 기본값을 가지면

- 내부가 비웠을 때 → 기본값을 채운다 (0.0065 동작)
- 내부가 바인딩했을 때 → **`fg-univ` 로 대조하고 어긋나면 그 대안을 버린다** (신규)

## 측정 (Maru)

| 항목 | 값 |
|---|---|
| 판정 일치(`lf-check` 대조) | **9/9** |
| 생성 문장 독립 검사기 수용 | **150/150** |
| 왕복 재인식 | **150/150** |
| 이빨① 주어 인칭 기본값을 1로 오선언 | 생성 표본 9건 중 수용 **0** |
| 이빨② 자식이 3인칭 바인딩 + 부모 기본값 1 | 표본 9건 중 수용 **0** |

이빨② 가 핵심입니다. 자식이 3인칭을 바인딩했는데 부모 기본값이 1이면 값 대조가 그 대안을
버립니다. 0.0065 의미론(채우기만)에서는 이 경우 **전부 통과**했을 자리입니다.

## 경계

- 두 이빨 팔은 하네스가 전역 선언을 잠시 바꿔치기해 측정합니다(`set *fg-decl*`). 모델 경로가
  아니라 게이트 하네스의 편법이며, 선언을 두 벌 두는 정식 경로는 아닙니다.
- 값 대조는 `fg-univ`(-1 을 무관으로 봄)를 그대로 씁니다. 따라서 `-1`(미지정) 내부값은 기본값과
  충돌하지 않습니다. 이는 `lf-check` 의 관대한 쪽과 같은 규약입니다.
- `a`/`an` 선택 규칙은 여전히 없습니다.
- 같은 선언에서 유도 트리·증명서를 뽑는 축은 0.0065 에서 철회한 상태로 남아 있습니다.
