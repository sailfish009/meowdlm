# meowdlm 0.0068 — 게이트 파손·값 대조 비활성·증명서 무검사 3건 수정

리뷰가 지적한 세 결함을 모두 인정합니다. 특히 **결함 1은 제 0.0067 진단을 뒤집습니다.**

## 결함 1 — 값 대조가 꺼져 있었고, 제 진단은 오진이었습니다

`fg-ifall` 은 정의만 되고 호출처가 없었고, `fg-ifvals` 는 `fg-if1` 의 판정 `(car r)` 을 버렸습니다.
그래서 0.0066 의 핵심인 **인터페이스 기본값 대조가 완전히 비활성**이었습니다.

수정: `fg-mcollect` / `fg-gcollect` 가 `fg-ifall` 을 먼저 호출해 **충돌 대안을 폐기**한 뒤에만
인터페이스 값을 산출합니다.

| 팔 | 0.0067 (버그) | **0.0068 (수정)** |
|---|---|---|
| `S` 기본값만 1로 단일 차분 → 표본 수용 | 9/9 | 10건 중 **1건**, 그중 **3인칭 0** |
| `i sleep` (1인칭 양성) | true | **true** |
| `Sbj` 기본값 차분 → NP 3인칭 단수 | 0/5 | **0/5** |

0.0067 문서에서 "S 차분이 무해한 것은 의미론상 S에 호출자가 없기 때문"이라고 쓴 진단은 **틀렸습니다**.
리뷰의 반증(패치 후 bad-S 가 3인칭을 전부 거부)이 맞습니다. 해당 문단은 이 릴리스에서 정정합니다.

## 결함 2 — verify.sh 파손

`fgrammar.l` 재작성으로 `def-fg`·`fg-mcat`·1인자 `fg-accept-gen` 등이 사라졌는데 섹션 31~33 이
`fgm64.l` 을 계속 호출해 code 18 로 중단됐습니다.

수정: 섹션 31~34 를 **현행 드라이버 `fgm68.l` 한 번 실행 결과**로 재작성하고, 각 섹션이 자기 릴리스의
주장만 검사하도록 분리했습니다(31 선언→인식/생성, 32 `=>` 선언·`bind` 0, 33 값 대조, 34 알파·중복).
섹션 35 를 신설해 이번 수정을 고정합니다. 전체 `./verify.sh` 가 끝까지 실행됩니다.

## 결함 3 — 증명서 검사기가 아무것도 검사하지 않았습니다

`fg-chk` 는 잎이 아니면 태그·루트 범주·ifv 를 보지 않았고, 선형화 재파싱은 단어열만 봤습니다.
그래서 태그를 `'BOGUS` 로, ifv 를 `((n . 999) (p . -42))` 로 바꾼 트리가 둘 다 통과했습니다.

수정: 증명서를 **국소 재유도**로 검사합니다.

- `fg-chk-tree`: 루트가 `S` 인 노드만 통과. 태그가 `node`/`leaf` 가 아니면 거부.
- `fg-chk-recon`: 노드마다 선언 규칙을 골라, 자식 기록(잎은 어휘 엔트리, 노드는 자식 ifv)으로
  `fg-cons`/`fg-cmatch` 를 국소 재실행하고 `fg-ifall` 로 인터페이스를 확정한 뒤 **노드의 ifv 와 대조**합니다.
- 규칙 내부에서 매개변수와 결과가 분리되므로, 이전에 오탐을 만들던 "부모 n = 자식 n" 전칭 비교는
  필요 없어졌습니다.

| 음성 팔 | 수용 수 |
|---|---|
| 태그 변조(`'BOGUS`) | **0/150** |
| ifv 변조(`n . 999`) | **0/150** |
| 루트가 `Obj` 인 서브트리 | **0/150** |
| 수 일치 위반으로 잎 교체(`sleeps`→`sleep`) | **0/150** |

## 표본 편향 (리뷰 관측 반영)

`fg-gchain` 의 단계 상한 6 과 고정 규칙 순서 때문에 COP 가지가 생성되지 않았습니다. 규칙별 결과를
**라운드로빈으로 혼합**하고 상한을 12 로 올려, 생성 372건 중 **COP 18건**이 포함됩니다.

또한 `DET`/`N` 수 일치를 `det-n` 가드로 분리하고(`N` 이 주어 수를 정하게) 동사 일치를 엄격형,
계사 일치를 관대형(`agree-cop`)으로 나눠, 생성물이 `lf-check` 와 100% 일치하게 했습니다.
